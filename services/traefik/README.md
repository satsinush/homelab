# 🔀 Traefik v3 Reverse Proxy

Traefik is the edge reverse proxy and TLS termination point for the homelab stack.

* **Official Documentation:** [doc.traefik.io/traefik](https://doc.traefik.io/traefik/)

---

## Overview

Traefik listens on HTTP (`:80`), HTTPS (`:443`), and the public Headscale VPN port (`:8443`). It routes external traffic to backend Docker containers using Docker socket provider labels.

## Architecture & Container Details

* **Container Name:** `traefik`
* **Configuration Files:**
  * Static config: `services/traefik/traefik.yml`
  * Dynamic middlewares: `services/traefik/dynamic_conf.yml`
  * Dynamic TLS config: `services/traefik/volumes/tls.yml`
* **Docker Socket:** `/var/run/docker.sock` (mounted read-only)

## Ports & Entrypoints

| Port | Entrypoint | Purpose | Access Control |
| --- | --- | --- | --- |
| `80/tcp` | `web` | HTTP → HTTPS redirect | Public LAN / VPN |
| `443/tcp` | `websecure` | HTTPS termination for internal homelab services | Internal LAN / VPN only |
| `8443/tcp` | `websecure-public` | Public HTTPS entrypoint for Headscale VPN | Internet / WAN |

## Certificate Resolver Modes

* **Private Mode (default):** Uses OpenSSL wildcard certificate generated by `./setup.py` at `volumes/certificates/homelab-server.crt`.
* **Public Mode (Let's Encrypt):** ACME DNS-01 challenge via Cloudflare (`cf_dns_api_token`). Certificates are managed automatically and dumped to `volumes/certificates/stalwart-tls/` by `traefik-certs-dumper`.
